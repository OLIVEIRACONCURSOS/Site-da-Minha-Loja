## 📚 Módulos da Plataforma
1. **Página Inicial (Home):** Banner institucional, cursos em destaque, atalhos rápidos OAB, categorias de Concursos Públicos e ofertas.
2. **Catálogo Dinâmico:** Filtros por categoria, fase, modalidade e preço com ordenação inteligente.
3. **Página de Cursos:** Informações detalhadas, cronograma, modalidade, preços via Pix e cartão.
4. **Carrinho e Checkout:** Sistema de pedidos com Pix manual e confirmação pelo administrador.
5. **Área do Aluno:** Biblioteca de cursos adquiridos, materiais via Google Drive e suporte.
6. **Painel Administrativo:** Gestão completa de cursos, alunos, pedidos, aprovação de pagamentos e relatórios.
7. **Canal Oficial de Promoções:** Integração direta com o WhatsApp oficial (`https://whatsapp.com/channel/0029VbDUiPKG8l5Fs1V8rh0w`).

## 🛠️ Tecnologias Utilizadas
- React, TypeScript, Vite e Tailwind CSS
- Lucide React para iconografia profissional
- Persistência em armazenamento local e serviços estruturados

## 🚀 Instalação e Execução
1. Clone o repositório.
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Para gerar a versão de produção:
   ```bash
   npm run build
   ```
